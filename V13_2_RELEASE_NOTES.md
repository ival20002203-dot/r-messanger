# Artel Link 13.2.0

Основной релиз стабильности realtime.

- новый глобальный `/ws/app/` для фоновых сообщений, уведомлений и presence;
- presence переведён с счётчика соединений на короткие client leases: закрытый/упавший клиент не оставляет пользователя online;
- отдельная периодическая сверка presence исправляет stale-online после аварийного закрытия;
- Desktop использует нативные Windows Notification через Electron main process;
- уведомления работают при сворачивании в трей и не зависят от permission Chromium;
- сообщения обновляют sidebar сразу через websocket; HTTP polling оставлен только fallback;
- курсор уведомлений хранится в localStorage, поэтому после перезапуска можно догнать пропущенные сообщения;
- один глобальный presence publisher вместо конкурирующих HTTP/chat websocket счётчиков;
- optimistic send `↻ → ✓ → ✓✓ / !` сохранён;
- CSS/JS получают version query string, чтобы клиенты не держали старую статику после серверного обновления;
- OTP SMTP получает короткий retry только для временных 4xx/сетевых сбоев.
