# R-Mes changelog

## 15.0.0

- New R-Mes blue/cyan visual identity and native splash experience.
- Telegram-like presence lifecycle with fast online/offline transitions and last-seen privacy.
- Developer audit visibility for exact user presence while privileged accounts remain hidden from normal users.
- Animated voice waveform, playback seeking and speed control.
- Native push-token bridge for Android FCM and iOS APNs.
- Multi-device sessions, revoke controls and deep-link routing.
- Native offline cache for recent app pages/static shell.
- Private call archive: call metadata and optional recording go to Developer Control Center only and never enter the chat timeline.
- WebRTC/TURN production configuration retained.
- 18+ moderation, security workers, DLP and antivirus pipeline retained and hardened.
- Admin/developer email 2FA can be required independently from normal-user login 2FA.
- Production HTTPS edge added through Caddy.
- Removed retired branding, green assets and legacy public documentation.
