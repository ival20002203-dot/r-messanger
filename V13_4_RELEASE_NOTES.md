# Artel Link 13.4.0 — Presentation reliability build

- Вложения больше не висят бесконечно в «Подготавливаем файл»: ClamAV worker ждёт health, использует длительный retry, UI опрашивает статус и показывает явную кнопку повторной проверки при реальной ошибке.
- Realtime: глобальный WebSocket остаётся основным, добавлены быстрые HTTP recovery циклы для sidebar, истории, unread и call signaling после сна/потери сети.
- Уведомления: фирменные Artel Link toast-окна в Desktop и in-app toast при активном приложении; cursor не теряет события при сбое показа.
- Звонки: сигнализация сохраняется в БД и дублируется polling fallback, TURN включается из .env; ICE-сигналы не теряются при переходе между чатами.
- 18+ модерация: MinIO/S3 файлы материализуются во временный локальный path для NudeNet; видеокадры также сканируются через path. Старые отключённые feature flags можно включить скриптом prepare_presentation.sh, который также переочередит старые error/pending jobs.
- Никаких удалений volumes/БД.
