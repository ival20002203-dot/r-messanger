# Artel Link 13.8.4

## Исправление времени

- Время сообщения формируется на сервере в `Asia/Tashkent` и передаётся одновременно как ISO, epoch и готовая строка `HH:MM`.
- Часы пузырей, списка чатов и уведомлений больше не пересчитываются через часовой пояс Windows/macOS/Android.
- Последнее посещение читается из свежей записи базы после heartbeat; несколько окон не затирают время друг друга.
- Отправка сообщения или файла через native API также фиксирует активность пользователя.

После установки достаточно обновить страницу один раз. Версия статических файлов меняется на 13.8.4, поэтому браузер и Desktop получают новый код внутри приложения.
