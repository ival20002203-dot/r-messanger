# Artel Link 13.8.2

Это обязательный release для исправления статуса «в сети» и времени последнего посещения.

## Что исправлено

- Redis больше не является единственной точкой для присутствия. Если `REDIS_URL` недоступен, статус и время сохраняются через серверную базу.
- Введено явное серверное состояние `presence_active`.
- Несколько окон одного пользователя объединяются в одну сессию: закрытие одного окна не сбрасывает остальные leases.
- Последнее закрытое окно сразу переводит пользователя в offline и сохраняет точное время сервера.
- Lease увеличен до 45 секунд, чтобы фоновые таймеры браузера не давали ложный offline.
- Клиент продолжает синхронизировать часы с сервером через `serverNow` и ответы presence API.

## Обязательное действие

После обновления необходимо выполнить миграции и перезапустить контейнеры. Проверка должна показать `TIME_ZONE=Asia/Tashkent`, актуальный `server_time`, работающий Redis и контейнер `web`.

Миграция: `accounts.0013_artel_link_v13_8_2_presence`.
