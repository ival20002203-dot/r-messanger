# Artel Link 13.8.3

## Исправлены время и языки

- Время сообщений и присутствия рассчитывается только сервером в `Asia/Tashkent`; клиент синхронизирует часы по каждому ответу API.
- Presence API принимает безопасный GET heartbeat, если старый клиент не смог получить CSRF-cookie. Последнее посещение обновляется при открытии чата и отправке сообщения.
- Ответ presence batch содержит `label`, `last_seen_at_ms` и `server_time_ms`, поэтому браузер больше не строит неверный статус из локальных часов.
- В настройках профиля доступны русский, English и O‘zbekcha. Выбор сохраняется на сервере и применяется после следующего запроса на всех устройствах.

Миграция: `accounts.0014_artel_link_language_preferences`.
