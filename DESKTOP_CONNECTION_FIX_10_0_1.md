# Artel Link 10.0.1 — Desktop connection fix

Исправлено поведение desktop-клиента до публикации production DNS:

1. Основной адрес остаётся `https://artellink.artelgroup.org`.
2. Если он ещё недоступен, desktop автоматически проверяет `http://127.0.0.1:8000`.
3. Если локальный Docker-сервер работает, приложение открывается без offline-экрана.
4. После публикации production-сервера клиент автоматически начнёт использовать корпоративный адрес.
5. Offline screen приведён к зелёному Artel-стилю.

Для локальной разработки web-сервис должен быть опубликован на порту 8000.
