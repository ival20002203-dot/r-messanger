# Artel Link 13.1.0

- Telegram-like Windows desktop notification preferences: sender name, preview text, sound, direct/group/channel categories, and suppression while the current chat is open.
- Global desktop notification polling for messages arriving in other chats while the app is minimized or not focused.
- Clicking a notification focuses Artel Link and opens the message.
- Notification permission test in Settings.
- Update banner no longer shows an endless “Готовится…”. It explicitly says when the installer has not been published.
- When an EXE/APK artifact is published, an open client rechecks every 10 seconds and changes the status to “Обновить” without reinstalling or restarting the server.
