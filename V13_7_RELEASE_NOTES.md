# Artel Link 13.7.0

## Исправлено

- Статус «был(а) в сети» рассчитывается по серверному времени и одинаково отображается в браузере и Desktop. Несколько окон одного пользователя больше не сбивают presence-состояние. Скрытие времени разработчика сохранено.
- Аудиозвонки переведены на надёжный глобальный сигналинг с повторной доставкой и независимым курсором каждого окна. Уведомление о входящем звонке приходит вне зависимости от открытого чата.
- Видеозвонки, кнопки камеры и разрешение Desktop на камеру удалены. Передача обычных видеофайлов оставлена.
- Добавлена очистка истории у себя и у обоих участников. Для защищённого диалога с разработчиком сервер сохраняет экземпляр разработчика, не раскрывая это обычному пользователю.
- Фото открываются во встроенной Telegram-подобной галерее. Вложения выдаются через защищённый same-origin endpoint и больше не перенаправляют пользователя на MinIO/S3.
- Голосовые сообщения получили живую дорожку при записи, таймер, отмену, отправку, визуальную дорожку при воспроизведении, паузу и перемотку.
- Статусы сообщений используют фактические delivery/read receipts: одна галочка после приёма сервером, две — после прочтения всеми получателями. Состояние синхронизируется между окнами.
- PDF и прочие файлы открываются или скачиваются через авторизованный endpoint; аудио поддерживает HTTP Range для перемотки.
- Проверки вложений продолжаются в фоне, а заражённые файлы блокируются после результата антивируса.
- Действия удаления, очистки истории, загрузки и звонков фиксируются в закрытом журнале. Административные и forensic-маршруты недоступны обычным пользователям.
- Desktop 13.7.0 получает обновления из собственного серверного feed, загружает их в фоне и предлагает перезапуск внутри приложения. Поддерживаются `latest.yml` и `.blockmap`.
