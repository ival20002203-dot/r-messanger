# R-Mes 15 — готовый релиз

Главное: точный online/last seen, privacy «точно/недавно/скрыто», голосовые с живой волной, push-готовность, multi-device, offline cache, файлы с прогрессом, WebRTC + TURN, 18+ модерация, антиспам, backups/monitoring, обязательная 2FA для админ-ролей и приватный архив звонков в Control Center.

Звонок и его запись **не создают сообщение в чате**. Метаданные/запись доступны Developer в `/control/calls/`.

Для Android/iPhone это отдельные устанавливаемые приложения. Android собирается в APK/AAB через Android Studio/SDK; iPhone — через Xcode/TestFlight/App Store с Apple-подписью.
