R-Messanger 15.1.2 — Screen Privacy + Call Privacy patch

ЧТО ИЗМЕНЕНО
1) Скриншоты / запись экрана запрещены всем, кроме Developer:
   - Windows Desktop: Electron setContentProtection(true), для Developer снимается после авторизации.
   - Android: FLAG_SECURE — скриншот и системная запись экрана дают чёрный/защищённый кадр; Developer исключён.
   - iOS: официально блокируется/закрывается чёрным экраном screen recording / mirroring и фон приложения. iOS не предоставляет публичного API, который гарантированно запрещает аппаратный screenshot; обычный screenshot нельзя обещать заблокировать на 100%.
   - Web browser: best-effort — при потере фокуса контент закрывается чёрным экраном. ОС-скриншоты обычной веб-страницы полностью запретить невозможно.

2) Developer exception:
   - после входа Developer native-защита снимается только для его приложения;
   - при навигации/выходе защита автоматически включается обратно до следующей подтверждённой developer-сессии.

3) Звонки:
   - надпись «ЗАПИСЬ ДЛЯ АДМИН-ПРОВЕРКИ» удалена;
   - скрытая аудиозапись НЕ выполняется;
   - в developer/admin журнале продолжают храниться метаданные звонка: кто кому звонил, начало, соединение, конец, длительность, статус/причина;
   - серверный upload аудиозаписи выключен по умолчанию CALL_AUDIO_RECORDING_ENABLED=0.
   - если в будущем понадобится аудиозапись, её лучше включать отдельно с видимым уведомлением/согласием участников.

УСТАНОВКА
1. Остановить сервер: Ctrl+C
2. Открыть PowerShell в папке этого патча.
3. Выполнить:
   Set-ExecutionPolicy -Scope Process Bypass
   .\APPLY_PATCH.ps1 -ProjectRoot "N:\VS CODE\localgram"
4. Запустить:
   cd "N:\VS CODE\localgram"
   .\scripts\run_dev_vscode.ps1
5. Browser: Ctrl+F5.

Миграции не нужны.
